# PARK 操作手順書（管理者向け）

PARK を管理する人が、**ログイン → 設定 → メールの処理**を、この順に進めるための手順書です。画面ごとの細かい説明は「管理者マニュアル」にあります。

## 1. 初めてのログイン

ほかの管理者が上のメニューの「管理者」→「管理者を登録」で**仮登録**すると、**仮登録のご案内**のメールが届きます（最初の1人は、システムの担当が本登録のリンクを作ります）。7日以内に**本登録**をします。

1. 仮登録のご案内のメールのリンクを開きます（期限は7日）。
2. 「本登録」の画面で、**企業名・お名前（姓・名）**をお確かめください（違っていれば直せます）。**電話番号**を入れ、パスワード（8文字以上）を2回入れて「**本登録する**」を押します。ふりがな・郵便番号・住所・所属・役職は任意です。心当たりがないときは、画面の「心当たりがない」を押します（リンクが無効になり、登録した方に知らせが届きます）。
3. 登録のメールアドレスに、**確認コード**のメール（件名：確認コード 123456）が届きます。6桁のコードを入れて「ログイン」を押します（10分間有効）。コードを入れると本登録が完了します。
4. 期限（7日）が切れたり、リンクが使えなくなったときは、登録した管理者に「送り直し」をご依頼ください。
5. ダッシュボードが開けば、ログインは完了です。画面の上に、青い帯で「管理者としてログインしています」と出ています。まだ SES・エンジニア・案件がないときは、いちばん上に「**PARK をはじめましょう**」が出ます。ボタンを上から順に押して進めます（済んだ手順には「済み」が付きます）。
6. ダッシュボードの「**登録の状況**」で、管理者と SES のご担当者の状態（参加中・仮登録・仮登録（期限切れ）・停止・担当者が未登録。退会済みの人は出ません）を確かめられます。仮登録の行には「**送り直し**」が出ます。

## 2. 2回目からのログイン

1. https://www.jona.jp/park/login を開きます。
2. メールアドレスとパスワードを入れて「ログイン」。前にログインしたことがあれば、メールアドレスは最初から入っています。
3. 届いた確認コードの6桁を入れて「ログイン」。

| こんなとき | すること |
|---|---|
| 確認コードが届かない | 迷惑メールのフォルダを見ます。無ければ画面の「コードを送り直す」 |
| 10分すぎてしまった・まちがえすぎた | 確認コードの画面を開き直すと、新しいコードが自動で届きます（まちがえすぎたときは、1分ほどたってから開き直します）。新しいメールの6桁を入れます |
| パスワードを忘れた | ログインの画面の「パスワードを忘れたとき」から、再設定のメールを受け取ります |

## 3. 最初の設定

### 3-1. アカウントの設定

1. 右上のお名前 →「**アカウント**」を開きます。
2. 「基本」の上の「**登録情報を見る**」を押すと、今の登録内容を見るだけの画面が開きます（「編集する」でアカウントに戻れます）。「基本」では、氏名（姓・名）・ふりがな（姓・名）・企業名・所属・役職・電話を確かめます（企業名は、あとからここで直せます。入れておくと、ご自分が送る案内メール・一斉送信・テストメール・仮登録のご案内の差出人の名前と署名が企業名になります。画面の上の「管理者（企業名）としてログインしています」にも出ます）。「**メールでも通知を受け取る**」には、チェックを入れたままにします（外すと、申し込み・応募・面談依頼などの知らせがメールで届かず、画面のベルだけになります）。「保存する」を押します。
3. パスワードを変えるときは、「パスワードの変更」で変えます（「変更する」を押します）。

### 3-2. PARK 全体の設定

上のメニューの「**設定**」を開きます。

| 項目 | すること |
|---|---|
| サービス名 | 「PARK」になっているか確かめる（メールの送り元・画面の名前に出ます） |
| 運営の名前（企業名が無いとき・自動のメールの署名） | 「PARK 管理者」など、メールの最後に出る名前。企業名を入れた管理者が自分で送るメールは企業名になります。通知・確認コード・パスワード再設定などの自動のメールは、いつもこの名前です |
| 初期費用・月額費用（%）・月額は何か月目から・消費税 | 成功報酬の計算に使う。決まったら直す |
| 配信候補に出す最低点 | マッチングの候補に出す点数（今は40点） |

変えたら「保存する」。

続けて、同じ画面の「メールの送信」で、「設定済み」と出ているか見ます。「**テストメールを送る**」を押し、自分にテストメールが届くことを確かめます。

管理者を増やすときは、上のメニューの「管理者」を開き、「**管理者を登録**」を押します。別の画面で、**企業名・氏名（姓・名）・メールアドレスの4つ**（すべて必須）を入れて「**仮登録してメールを送る**」を押すと、ご本人に仮登録のご案内が届きます（7日以内に本登録。電話番号などは、ご本人が本登録で入れます）。本登録が済むと「参加中」になり、管理者全員に知らせが届きます。一覧のその行の「**詳細**」で見られ、詳細の「**編集**」で直せます。仮登録の間に直せるのは、企業名・氏名・メールアドレスの4つで、メールアドレスを変えると新しいアドレスにご案内を送り直します（前のリンクは使えなくなります）。本登録が済んだ人は、氏名・企業名・所属・役職・電話番号・郵便番号・住所を直せますが、電話番号など必須の欄は空にできません（メールアドレスは変えられません。ご自分・停止中の人のメールアドレスも変えられません）。状態が「仮登録」のまま期限（7日）が切れた人（「仮登録（期限切れ）」）には、その行の「**送り直し**」を押します。間違えて登録したときは、仮登録の行の「**取り消し**」（確認が出ます）で行を消せます。本登録が済んだ人には「取り消し」は出ません。
管理者を止めるときは、一覧のその人の行（または詳細の右上）の「**停止**」（止めているときは「**再開**」）か「**退会**」を押し、確認で「OK」を押します。ご自分の行には出ません。停止は再開で戻せますが、退会は元に戻せません（手順は 3-4）。

SES を管理者が仮登録するときは、「SES」→「SES を仮登録」。**企業正式名称・SES の姓・名・メールアドレスの4つ**を入れて「仮登録してメールを送る」を押すと、SES に仮登録のご案内が届きます（7日以内に本登録）。SES が本登録（確認コードまで）を済ませると、会社が「参加中」になり、管理者全員に知らせが届きます。一覧と詳細で、状態（仮登録・期限切れ）の確認と「送り直し」「仮登録の内容を直す」「取り消し」ができます。公開の申し込みを承認するときは、会社の詳細の「承認する」から、同じ4つの入力画面で確かめて送ります。

担当者を管理者が登録するときは、「SES」でその SES の「詳細」を開き、「担当者」の欄の「担当者を登録」を押します（参加中の SES だけ）。**姓・名・メールアドレスの3つ**を入れて「仮登録してメールを送る」を押すと、担当者に仮登録のご案内が届き、その会社の SES にも知らせが届きます。

エンジニアを管理者が登録するときは、上のメニューの「SES一覧」でその SES の「詳細」を開き、「エンジニア」の欄の「エンジニアを登録」を押します（管理者のメニューの「エンジニア一覧」の一覧からは登録できません）。**姓・名・メールアドレスの3つ**を入れて「仮登録してメールを送る」を押すと、ご本人に仮登録のご案内がその場で届き、SES にも知らせが届きます（ふりがな・電話・住所・同意は、ご本人が本登録で入れます）。担当者・エンジニアの行の「送り直し」「仮登録の内容を直す」「取り消し」は、本登録が済む前の方に出ます。

エンジニアの詳細の「推薦文（社内用）」のカードでは、SES・担当者が登録した推薦文を読めます（読むだけです。登録・更新・消すのは、そのエンジニアの SES・担当者です。管理者の仮登録の画面には推薦文の欄はありません）。推薦文には個人情報が含まれ、ご本人・ほかの会社には見えません。「設定」→「技術マスタ」には、分類「語学・海外」が増えています。

SES を交代するときは、「SES」の詳細の「SES の交代」で、本登録が済んだ担当者を選んで「SES にする」を押します（担当者がいない会社は、「次の SES を仮登録する」）。SES は、交代のあとでなければ停止・退会にできません。エンジニアは、必ず SES の所属です（管理者に直接つくエンジニアはいません）。

**管理者が担当者を兼ねるとき**：管理者は案件を案内できません。案内したいときは、「SES」の詳細の「担当者」の欄の「この会社の担当者を兼ねる」を押します（1社だけ。会社の SES・担当者にお知らせが届きます。やめるときは「兼任をやめる」）。ログインのとき「SES 担当者（会社名）」を選ぶと、その会社の案件を案内できます（管理者の立場では案内できません）。

### 3-3. エンジニアを兼ねる（兼任）

1. 管理者が自分もエンジニアとして入るときは、「SES」でその SES の詳細を開き、「エンジニアを登録」でメールアドレスに**ご自分のメールアドレス**を入れて登録します（仮登録のご案内は出ません）。
2. 「ログアウト」して入り直し、確認コードのあと、「どの立場で入りますか」で「エンジニア」を選びます。初めてのときは、足りない項目と同意の画面が出ます。
3. SES 担当者のメールアドレスで同じ SES のエンジニアを登録しても、兼任になります。「担当者を登録」「管理者を登録」でエンジニアのメールアドレスを入れると、担当者・管理者の役割が足されます。
4. 管理者の立場で自分のエンジニアの分を進めると、記録に「［本人］」が付きます。

### 3-4. 管理者・担当者・エンジニア・SES を止める・退会にする

1. 上のメニューの「SES一覧」から、その会社の詳細を開きます。
2. 「担当者」または「エンジニア」の表の、その人の行の「停止」（止めているときは「再開」）か「退会」を押し、確認で「OK」を押します。押すと、SES の詳細に戻ります。
   - 「SES」「エンジニア」「管理者」の一覧の各行にも同じボタンがあります。一覧から押したときは、一覧（絞り込みはそのまま）に戻ります。
   - 会社ごとの停止は、「SES」の一覧の行か詳細の右上の「停止」です。停止中は「再開」で戻せます（仮登録のご案内は送りません）。
   - 管理者は、「管理者」の一覧か詳細で止めます。ご自分は止められません。使える管理者がほかにいなくなる操作もできません。
3. 内容を見たいときは「詳細」を押します。担当者の詳細の画面でも、停止・再開・退会ができます（押すと、その画面に戻ります。エンジニア兼任の人を退会にしたときは SES の詳細に戻ります）。
   - 退会は元に戻せません（記録は残ります）。
   - 稼働中の契約があるエンジニアは、退会にできません（先に契約を終了します）。
   - 使える担当者が1人だけの会社では、その人を止めたり退会にしたりできません。
4. 退会済みの会社・担当者・エンジニアは、「SES」「エンジニア」の一覧と、SES の詳細の「担当者」「エンジニア」の表では、はじめは出ません。見るときは「退会済みを表示する」を選んで「**絞り込む**」を押します（表の下の［表示する］でも同じです）。グレーの行で出ます。詳細の画面の題は「ID　名前　退会済み」になります。

## 4. メールの処理

管理者が扱うメールは、**PARK から届く知らせ**、**元請けからの案件メール**、**PARK が送ったメールの確認**の3つです。毎日の流れは、ダッシュボードのいちばん上の「**今やること**」を上から片付けるのが基本です。メールの知らせも、そこに出ます。

### 4-1. PARK から届く知らせ

どのメールにも「▼詳しくはこちら」のリンクがあり、押すと PARK の該当の画面が開きます。

| 届くメール（件名） | すること |
|---|---|
| 確認コード 123456 | ログインの画面に6桁を入れる |
| SES から参加の申し込みがありました | 「SES」から会社を開き、「**承認する**」。企業正式名称・SES の姓名・メールを確かめて送ると、SES に仮登録のご案内が届く |
| SES から案件が登録されました | 案件を開き、金額・必須スキルなどを確かめる。案内は受注 SES の担当者が行います（管理者は案内できません。案内メールの記録は読めます） |
| エンジニアが登録されました | エンジニアの詳細を開き、内容を確かめる |
| エンジニアの推薦がありました | 案件の画面で、推薦された人を確かめる。案内は受注 SES の担当者が行います（担当者の画面の「エンジニアを検索」→「エンジニアを選択」。他社の人は、その会社の担当者への紹介の依頼になります） |
| 応募がありました | 応募の画面で条件を確かめ、案件に合わせたスキルシートを元請けに出して「スキルシートを提出した」（スキルは節ごとに、チェックした項目と年数が出ます） |
| 応募の取り下げ | 応募の画面で理由を確かめる |
| SES から面談依頼の報告 | 面談の画面で、面談スクリプトの中身を確かめ、必要なら直す |
| ◯◯ さんからメッセージ | 「エンジニアとのやり取り」で読んで返事をする（「スキルシートを見てほしい」なら、スキルシートを確かめる） |
| エンジニアから案件の質問が届きました（会社に使える担当者がいないとき） | 「案件のやり取り」で開いて読む（管理者は読むだけです。担当者の登録を急ぐ。下の「4-8」） |
| どの案内メールへの返信か分からない受信メールがあります | 「受信メール」で開いて読み、案内メールに紐付けるか、対象外にする（下の「4-9」） |
| フォロー：困りごとがあります | 契約の画面で中身を読み、本人・SES と連絡を取る |
| 案件から新しい技術を技術マスタに追加しました | 「設定」→「技術マスタ」で分類と別名を確かめ、「確認済みにする」（言い換えなら「統合」）。「使っている人」は経歴の分も数えます。統合すると経歴の索引が付け替わります（スキルのチェックは項目の名前で持つので変わりません）。確認済みにすると経歴の索引が作り直されます |

### 4-2. 元請けから案件メールが届いたら

1. 「案件」→「**案件を登録**」。
2. 案件メールの本文を「**案件メールから取り込む**」に貼り付けて「取り込む」。
3. 「**受注 SES（必須）**」を選び、抜けているところ・違うところを直して「登録する」（元請けの名前は伏せ字でかまいません）。必須・尚可は技術マスタの名前になり、拾えない文は「**エンジニアに確認**」の欄に入ります。内容を確かめ、会社名などは消してください（エンジニアに見える欄です。点数には使いません）。選んだ SES の担当者全員に、お知らせとメールが届きます。登録すると、手元の AI が必須・尚可を読み直します（1件 1分ほど）。
   - 規則と同じ数で、人が直しておらず、案内もまだなら、AI の結果が自動で入ります。
   - そうでないときは知らせが届きます。案件の画面の「**AI の読み直し**」で、違いの表を見て「AI の結果を使う」か「今のままにする」を選びます。
   - 案内したあとは、AI の結果は自動では入りません。「設定」の「AI の仕事」で、頼んだ仕事の状態を見られます。
4. **案内は、受注 SES の担当者が行います**（管理者は案内できません。案件の画面に「案内は、受注 SES（◯◯）の担当者が行います。」と出ます）。担当者の立場の流れ：案件の画面の「エンジニアを検索」で項目をチェックで選ぶ →「エンジニアを検索」→「エンジニアを選択」で選ぶ（必須の4分の3以上に当たった人）→「エンジニア・担当者へメールを作成」→ 作成画面で本文（単価など）を直して、プロパー → 担当者の順に送る。PARK に登録していない宛先（追加の宛先）に送ったものは、案件の画面の「案内済メール」の下の「追加の宛先」の表で、パートナーの担当者に紹介を頼んだものは「担当者への依頼」の表で、読むだけ見られます。
5. 管理者は、案件の画面の「案内済メール」で、送った記録と返事を読めます（記録のボタンはありません）。

### 4-3. PARK が送ったメールを確かめる

1. 上のメニューの「**メール**」を開きます。送ったメールがすべて「送信箱」に残っています。
2. 「状態」が失敗のものは、エラーの中身を見て、宛先を直すなどしてから送り直します（「中身」→ 送り直す）。
3. 「届かない」と言われたときも、ここでその人宛てのメールの状態を見ます。

### 4-4. お知らせを一斉に送る

1. 「メール」の右側の「**一斉配信**」で、宛先（参加中の SES の担当者すべて・エンジニアすべてなど）を選びます。
2. 件名と本文を書いて「配信する」（宛名は自動で入ります）。
3. 確認の窓で「OK」を押すと、すぐに送られます。送る前に、宛先と本文をよく確かめてください。

### 4-5. エンジニアの所属の SES を変える

1. 上のメニューの「**エンジニア**」から、その人の詳細を開き、「**編集**」を押します。
2. 画面の下の「**所属**」のカードで、「変更先」から会社を選びます（参加中の SES から選べます）。
3. 「**所属を変える**」を押し、確認の窓で内容（元の会社から新しい会社へ）を読んで「OK」を押します。
4. 「所属を「…」に変えました」と出れば完了です。元の会社の SES・担当者にはその人が見えなくなります。過去の応募・契約・請求は元の会社のままです。
5. カードに理由の文だけが出ているときは、変えられません（稼働中の契約・選考中の応募・兼任・退会済み）。契約や選考が終わってからやり直します。
6. **仮登録中の人**は、この画面ではなく、エンジニアの一覧の「仮登録の内容を直す」から所属を直します。
7. SES・担当者が自社のエンジニアを移したときは、管理者にお知らせが届きます。

### 4-6. エンジニアに連絡メールを送る

案件に結び付かない、自由な件名・本文のメールです。

1. 上のメニューの「**エンジニア**」を開きます。
2. 送りたい人の行の「選ぶ」にチェックを入れます（「全選択」で、表示中の全員にもできます。仮登録・停止中・退会の人にはチェックが出ません）。
3. 一覧の上の「**選んだ人にメールを送る**」を押します。1人だけのときは、エンジニアの詳細の「**メールを送る**」でも同じ画面に進めます。
4. 件名と本文を書き（件名 100 文字・本文 5000 文字まで。1回に 50 人まで）、「**送る**」を押します。「n名に送ります」の確かめで「OK」を押すと、送られます。2回押しても、1回分だけです。
5. 送ったあとの「連絡メール」の画面で、本文と、宛先ごとの状態（送った・保存のみ・失敗）を確かめます。上のメニューの「**連絡メール**」の「送った」「すべて」から、いつでも見られます。
6. 管理者から送ったメールには、返信先を付けていません。返事は、PARK の共通の差出人アドレスに届きます。
7. 担当者を兼ねている会社のエンジニアから連絡メールが届いたときは、PARK のお知らせが出ます（担当者の立場）。「連絡メール」の「受け取った」で読みます。

### 4-7. ID（番号）で探す

「CA-12 の件」のように ID を言われたとき、その詳細をすぐ開く手順です。

1. 画面の上の青い帯の「**ID で探す**」に、ID を入れます（`CA-000012` のほか、`ca12`・`ＣＡ－１２` のような略し方・全角でも大丈夫です。前の1文字の形 `C-12` で書かれた古いメールの ID も、そのまま探せます）。
2. 「**探す**」を押すと、案件・エンジニア・応募・契約・請求書などの詳細が開きます。
3. 「その ID は見つからないか、開けません。」と出たときは、ID の打ち間違いか、まだ付いていない ID（下書きの請求書は、発行したときに付きます）です。
4. エンジニアの一覧は、検索の欄に ID を入れても絞り込めます。
5. お知らせとメールの題の終わりの `［CA-000012］` が、その ID です。

### 4-8. 案件のやり取りを見る・返事をする

エンジニアが案件について担当者に書いた質問を、見たり、返事をしたりする手順です。

1. 上のメニューの「**案件のやり取り**」を開きます（お知らせ・メールのリンク、ホームの「今やること」、案件の画面の「エンジニアとのやり取り」からも開けます）。会社で絞れます。
2. 見たいやり取りの「**開く**」を押します。管理者は、どの会社の1本も読むだけです（書けません。入力欄の代わりに「管理者は、やり取りを読むだけです。」と出ます）。
3. 返事を書くのは、相手の会社の担当者です。
   - 一覧の「相手」の列は、書ける相手です（受注 SES）。
4. 管理者のホームの「今やること」には、やり取りは出ません。
5. **会社の1本**は、管理者が開いても、会社の担当者の「未読」は消えません（担当者が気づく前に、管理者が読んだだけで消えないようにするためです）。
6. 「書けません」と理由が出たときは、案件が募集を終えている、エンジニアが停止中・退会済み、会社が参加中でない、などです（履歴は読めます）。
7. 案件のやり取りは、案件の画面の「配信済み」の「やり取り」からも開けます（読むだけです）。

### 4-9. 受信メールを確かめる・紐付ける

エンジニアが案内メールに返信したメールを、PARK が受信箱（park@jona.jp）から取り込みます。取り込めるのは、受信の設定（`.env` の `PARK_IMAP_*`）が入っているときだけです。

1. 上のメニューの「**受信メール**」を開きます。上に受信の状態（設定の有無・最後に取り込んだ日時）、タブ「未紐付け／紐付け済み／対象外／すべて」が出ます。
2. 受信の設定があるときは、「**今すぐ取り込む**」を押すと、いま受信箱にある新しいメールを取り込みます（設定がないときは「受信の設定がまだです（.env）」と出て、何もしません）。ふだんは 5 分ごとに自動で取り込みます（`cron` の設定。README）。受信箱のメールは消さず、既読にもしません。
3. 一覧の「開く」で、本文・添付の名前・差出人を読めます。管理者は、**すべての会社のエンジニアの返信を、氏名を伏せずに**読めます（公平性のルールの対象です）。「元のメール（.eml）」で、元のメールを取り出せます。
4. **未紐付け**（どの案内メールへの返信か分からなかったもの）は、管理者のお知らせとホームの「今やること」に出ます。開いて、次のように紐付けます。
   1. 「案件 ID（CA-）」に案件の ID を入れて「探す」。その案件の案内メールの一覧（エンジニア・所属の会社・送った日）が出ます。
   2. 返信に当たる行の「これを選ぶ」を押すと、確認が出ます。「この返信は、◯◯ の担当者に見えるようになります」を読み、間違いがなければ「**紐付ける**」を押します（選び間違えると、ほかの会社に見えてしまいます）。
   3. 紐付けると、受注 SES の担当者全員にお知らせが出ます。操作は記録に残ります。
5. 営業メールなど、案内と関係のないものは「**対象外にする**」（理由は書いても書かなくてもかまいません）。間違えたときは「未紐付けに戻す」。
6. 間違って紐付けたときは「**紐付けを外す**」。外すと担当者からは見えなくなり、付け直せます。
7. 不達の通知・自動返信には「自動」の印が付き、担当者へのお知らせは出ません。
8. 取り込んだメール・元のメール（.eml）を消す操作は、画面にはありません。

### 4-10. プロバイダーへの返信とプロバイダーからの結果報告を読む（読むだけ）

1. 案件の画面を開くと、枠「プロバイダーへの返信」に、下書き・送ったもの（エンジニア・意向・状態・日時）が出ます。「開く」で、宛先・文面・メールの状態を読めます。「案内済メール」の「プロバイダーからの結果報告」の列で、結果とメモを読めます。
2. 管理者には、送る・保存・取りやめる・作り直す・結果の登録のボタンは出ません（URL を直接開いて押しても 403 です）。操作は、受注 SES の担当者が行います。担当者を兼ねている場合は、担当者の立場に切り替えて操作します。
3. プロバイダーの返事は「受信メール」で読めます（差出人は「企業名（プロバイダー）」）。送ったメールへの返事の件数は、送ったあとの画面の「プロバイダーからの返信」から開けます。
4. 本物のプロバイダーに送り始めるときは、送信元のアドレス（park@jona.jp）が相手に見えることを承知しておいてください。

### 4-11. エンジニアの担当者を付け替える

1. メニューの「エンジニア一覧」から、付け替えたい人の「編集」を開きます。
2. 「担当者を付け替える」で、その会社の担当者（SES を含む。ほかの会社の人は出ません）から選び、［付け替える］を押して、確認で「OK」を押します。
3. 新しい担当者・前の担当者・ご本人にお知らせが届きます（メールは届きません）。下の「付け替えの記録」で、日時・前・後・した人・理由を確かめられます。
4. 一覧の「担当者」の列でも確かめられます。

### 4-12. 受けた案件の原文（全社）と、パートナーの追跡を読む（読むだけ）

1. メニューの「プロバイダー一覧」の［受けた案件（原文）］のタブを開きます。全社の案件が、「受注 SES」の列つきで出ます。［原文］を押すと、プロバイダーからのメールの原文が開きます。プロバイダー・状態・言葉で絞り込めます。
2. 案件の画面の「案内済メール」の、「担当者経由」の行の返事の欄に、「提案の依頼：日付」と「最後の結果：成約（日付）」が出ます。管理者は読むだけです（［受注 SES に提案を頼む］・最後の結果の記録は 403 です）。
